# StreamChat 0.4.0 — Windows Preview

Локальный единый чат Twitch и YouTube от **fromflamb**. Electron, React, TypeScript; настройки, профили и история хранятся на вашем компьютере. Это Preview: установщик пока без цифровой подписи. API подготовлен к размещению на `https://api-streamchat.fromflamb.ru`; доступность production-сервиса и реальные входы проверяются после его развёртывания.

## Установка и запуск

В опубликованном GitHub Release скачайте `StreamChat-Setup-0.4.0.exe` и пройдите мастер установки. Он устанавливает приложение для текущего пользователя, позволяет выбрать каталог и создаёт ярлыки. Локально собранный файл находится в `release/`. Windows может показывать предупреждение для неподписанного Preview. Публичный Release этой рабочей сессией не создавался.

Для запуска из исходников нужен Node.js 24.12+ с npm:

```powershell
npm ci
npm run build
npm start
```

Либо дважды нажмите `Start StreamChat.bat`. Для разработки — `npm run dev`, для установщика — `npm run package:win`.

## Интерфейс

- **Чат** — стартовый экран. Без подключений здесь onboarding и демо. ПКМ / Shift+F10 по сообщению открывает ответ, копирование, удаление и модерацию с проверкой прав. Карточка зрителя нужна для истории и подробностей.
- **Аккаунты** — одинаковые карточки Twitch и YouTube, статус подключения, переподключение, отключение, выход и выбор канала. Twitch сразу запрашивает необходимые права чата и модерации; старой сессии может потребоваться повторный вход.
- **Оформление** — семь стилей с настоящими мини-превью, цвета имён, фон, шрифт, размер и плотность. Дополнительные параметры спрятаны в Advanced. Live Preview и OBS используют общий renderer. Сохраните профиль для применения к OBS.
- **Настройки** — одна колонка: интерфейс, звуки и движение, безопасность чата, обновления и экспериментальные возможности. Выбор шрифта и оформления находится только в «Оформление».
- **Инструменты разработчика** — отдельный пункт, появляется при Experimental. Здесь диагностика, демо и технические параметры. URL-каналы также доступны в Experimental; модерация в них невозможна.
- **OBS** — кнопка «Добавить чат в OBS» выдаёт локальный URL для источника «Браузер». Разумные Auto-значения зависят от размера текста и плотности. [Подробности оформления](docs/CHAT_APPEARANCE.md).
- Внизу навигации — Boosty, DonationAlerts и `by fromflamb`. Ссылки открывает main process по фиксированному списку HTTPS-адресов.

RU/EN меняется без перезапуска. Ctrl+, открывает настройки, Ctrl+1 — чат, Ctrl+2 — аккаунты, Escape закрывает меню/диалог. Системный tray и автозапуск ещё не реализованы.

## Обновления

В установленной Windows-версии StreamChat проверяет GitHub Releases. Автозагрузка включена по умолчанию; установить загруженную версию можно только отдельной кнопкой. При обычном закрытии обновление не устанавливается. В dev, portable и `win-unpacked` проверка выключена. Для работы нужен опубликованный Release с `.exe`, `.blockmap` и `latest.yml`.

## Конфигурация и приватность

Обычному пользователю установщика `.env` не нужен. Main process получает публичные Client ID от StreamChat API. Google secret и YouTube API key остаются на сервере. OAuth-код с PKCE verifier и refresh token проходят через специализированные HTTPS-методы API при обмене/обновлении Google-сессии; сервер их не сохраняет и не логирует. Чат авторизованных аккаунтов идёт непосредственно к платформам; публичные YouTube URL-чаты читаются через ограниченный proxy.

В разработке `.env.example` содержит только публичные настройки. Существующая локальная конфигурация совместима; она не загружается в packaged build. Не добавляйте секреты в `VITE_*`, исходники или Git. API — отдельный репозиторий `stream-chat-api/`, исключённый из Desktop Git.

Локальные данные обычно находятся в `%APPDATA%/streamchat/` (точный путь — в диагностике): `streamchat.sqlite`, отдельная `demo.sqlite`, `window.json`, диагностические логи. OAuth-сессии защищены Electron safeStorage/Windows DPAPI. Перед резервной копией закройте приложение. Старые профили/настройки мигрируются при чтении без удаления данных. Глобальный буфер остаётся 2000 сообщений; лимит OBS независим.

## Проверки

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run test:desktop
npm run test:appearance
npm run test:oauth
npm run test:phase4
npm run test:motion
npm run test:safechat
npm run test:release
node scripts/secret-scan.mjs
```

Desktop-тесты требуют графической Windows-сессии и установленного Edge. Они используют отдельные данные `test-results/` и имитацию провайдеров. Реальные OAuth, модерация, нативный OBS, установка/удаление и обновление между опубликованными версиями требуют ручной проверки. API rate-limit/квота хранятся в памяти одного экземпляра; публичный массовый запуск потребует контроля квоты и защиты на reverse proxy.
