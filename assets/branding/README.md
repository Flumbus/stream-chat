# StreamChat logo

Export of the existing App.tsx brand mark: Lucide MessageSquare (18/32), rounded square (radius 9/32), rotation -6 degrees.

Purple #c299ff sampled from the supplied screenshot; foreground #1b2610 matches styles.css. SVG and PNG files have transparent outer backgrounds and a square canvas with room for the rotated mark. PNG sizes: 1024 and 256 pixels. Suitable as source assets for a future ICO.

The MessageSquare glyph comes from lucide-react; its license is included alongside these assets.
