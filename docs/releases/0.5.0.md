# StreamChat 0.5.0 Alpha — начало Phase 5

- Верхняя панель: после названия показаны версия установленной сборки и метка Alpha. Номер приходит из Electron `app.getVersion()` через защищённый IPC, а не из JSX.
- Крестик и Alt+F4 скрывают окно в системный трей. Соединения, сообщения, локальная БД и OBS overlay продолжают работать.
- Клик/двойной клик по значку трея, пункт «Открыть StreamChat» и повторный запуск возвращают существующее окно, в том числе из свёрнутого состояния.
- Меню трея содержит версию, «Открыть StreamChat» и «Выйти из StreamChat». Язык RU/EN обновляется вместе с настройками.
- Полный выход закрывает backend и удаляет значок. Перезапуск updater проходит через настоящее завершение, не скрывается в трей.
- Сохранены исправления updater из подготовки 0.4.1 и короткие подписи Dev Tools/Boosty/DonationAlerts.

Alpha обозначает зрелость приложения; технический номер — `0.5.0`. Существующий канал `latest.yml` сохранён для обновления установленных 0.4.x. Публикация запускается тегом `v0.5.0`: workflow проверяет файлы, загружает их в черновик, затем делает релиз публичным. Публичные примечания находятся в `0.5.0-public.md`.

Ограничения: Windows может размещать значок в скрытой области трея. Автозапуск при входе в Windows не добавлен. Если создание значка не удалось, обычное закрытие разрешается и пишется `TRAY_UNAVAILABLE`, чтобы не оставить приложение без способа вернуть окно.

Проверки: typecheck/build/lint, 166 тестов, Phase 4/Phase 5/Release/Packaged desktop scripts. Phase 5 также пройден непосредственно в packaged exe. Собран NSIS 0.5.0; скан app.asar не обнаружил секретов. Физический клик по Windows shell, завершение сессии Windows и установка обновления между двумя публичными версиями не проверялись.
