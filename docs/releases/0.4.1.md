# StreamChat 0.4.1

Исторические примечания к локальной подготовке: 0.4.1 не публиковалась. Эти исправления вошли в публичный 0.5.0 Alpha.

- Обновления: приложение различает отсутствие опубликованного релиза, неполный релиз, сетевой сбой, ошибки проверки файлов и запуска установщика.
- Повторная проверка очищает предыдущую ошибку и устаревшие сведения о доступной версии.
- В локальном журнале сохраняются только безопасные коды ошибок updater, без ответов GitHub и подписанных URL скачивания.
- Короткие подписи в интерфейсе: Dev Tools, Boosty, DonationAlerts.

Для пользователей установленной 0.4.0 обновление появится после публикации обычного публичного GitHub Release `v0.4.1` с установщиком, `.blockmap` и `latest.yml`. Черновики и prerelease не входят в текущий канал обновлений. Публикация исходников или API сама по себе не создаёт обновление Desktop.

Проверено: typecheck/build/lint, 160 тестов в 21 файле, `test:release`, `test:packaged`, сканирование app.asar (3910 файлов, секретов не найдено). Реальный GitHub-запрос из копии packaged exe с тестовым marker установки и отдельной БД подтвердил `UPDATE_NOT_PUBLISHED` и запись безопасного кода в журнал. Настоящая установка через NSIS и обновление между двумя публичными версиями пока не проверены. Установщик остаётся без Authenticode-подписи.
