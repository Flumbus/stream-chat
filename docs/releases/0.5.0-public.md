# StreamChat 0.5.0 Alpha

Начало Phase 5: локальный чат Twitch и YouTube для Windows.

### Что нового

- Актуальная версия и метка Alpha после названия в верхней панели.
- Закрытие крестиком или Alt+F4 скрывает окно в трей. Чат и OBS overlay продолжают работать.
- Клик по значку трея возвращает окно. В меню доступны «Открыть StreamChat» и «Выйти из StreamChat».
- Повторный запуск возвращает уже работающее окно.
- Понятные сообщения о сбоях обновления и исправление повторной проверки после ошибки установки.
- Короткие названия Dev Tools, Boosty и DonationAlerts.

### Обновление с 0.4.x

В установленном StreamChat откройте **Настройки → Обновления → Проверить обновления**. После загрузки нажмите **Перезапустить и установить**. Настройки, профили и история сохраняются.

Для ручной установки скачайте **StreamChat-Setup-0.5.0.exe**. Файлы `latest.yml` и `.blockmap` нужны автоматическому обновлению; отдельно открывать их не нужно.

Сборка Alpha для Windows x64. Установщик пока без цифровой подписи. Значок приложения может находиться в скрытой области системного трея.
