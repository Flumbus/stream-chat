### Интерфейс и поведение

- В «Настройки → Безопасность чата» добавлены переключатель «Скрывать ссылки зрителей» (ON) и выбор «Команды»: показывать / заменять на `***` (default) / не показывать сообщение. `!discord` и `!so flamberor` маскируются целиком; обычное предложение с `!` в конце остаётся прежним.
- В редакторе безопасности второстепенный раздел «Команды и ссылки · подробно» содержит дополнительные префиксы, разрешение ссылок подписчикам/участникам (OFF) и список доверенных пользователей. ПКМ на сообщении со скрытой ссылкой позволяет разрешить ссылки этому пользователю; запись привязана к platform + user ID, имя служит только подписью. Изменения пересчитывают текущий буфер и OBS snapshot.
- У обычного зрителя удаляется только URL, соседние пробелы нормализуются. Поддержаны http/https, www, bare domains, example.ru/path, discord.gg и t.me. Сохраняются незатронутые emotes. Несогласованные fragments не могут вернуть скрытый текст.
- Доверие определяется нормализованными ролями/ID значков платформы: broadcaster/owner, moderator, VIP, подтверждённый bot; либо явным списком ID. Имя с суффиксом bot, подпись значка и права оператора не дают доверия отправителю. Subscriber/member/sponsor/founder требуют отдельного opt-in; YouTube verified не даёт разрешения автоматически. Неизвестный автор цитаты считается недоверенным.
- Пустой результат не передаётся в OBS/public snapshot и incremental packets, не создаёт bubble в preview. Локально остаются пояснение и действие открытия оригинала. Snapshot исключает пустые строки **до** применения display limit: поток скрытых ссылок не вытесняет видимые сообщения. Удалённая из безопасного snapshot строка не задерживается в OBS ради exit-анимации.

### Совместимость и безопасность

Settings schema остаётся version 1: отсутствующие новые поля получают defaults (mask, префикс `!`, ссылки скрыты, subscriber opt-in OFF, доверенный список пуст). Старый `hideCommands: true` при нормализации темы перестаёт быть отдельным фильтром; командой управляет глобальный режим с default mask. Явно выбранный новый режим show/hide сохраняется. Остальные свойства темы/appearance, профили, аккаунты, URL и глобальный буфер не сбрасываются; SQL migration не нужна.

Оригинал остаётся в локальном main buffer; public DTO не содержит локальных аннотаций или копии оригинала. Проверены renderer/overlay на HTML sinks: `dangerouslySetInnerHTML`, `innerHTML`, `insertAdjacentHTML` отсутствуют. React выводит текст с escaping; регрессия с `<img onerror>` и `<script>` проверена в Electron и OBS-странице Edge при отключённых текстовых фильтрах.

Детектор ссылок консервативный: не делает сетевых запросов, не раскрывает редиректы, не распознаёт намеренно разнесённые по пробелам/словам домены. Агрессивный Experimental-режим не добавлялся. Реальные платформенные роли/permissions и нативный OBS требуют ручной проверки; автоматизированный OBS-прогон использует Edge Chromium.

## Phase 4.7–4.8 — актуальная реализация (29.09.2026)

Сначала завершён motion pass, выполнена отдельная регрессия и записаны результаты 4.7. После этого реализован Safe Chat, снова выполнена регрессия. Старые записи ниже сохранены как история.

### Motion

`renderer/motion.ts` задаёт 90/140/190/240 ms и easing enter/exit/move; stylesheet использует соответствующие CSS tokens. `useMotionValue`, `MotionPresence`, `MovingIndicator`, `AnimatedDetails`, `CopyButton`, `ConnectionFeedback` разделяют поведение переходов и feedback. Native semantics summary/keyboard сохраняются; скрытое содержимое accordion inert. Меню поддерживает стрелки, Home/End, Escape, submenu и inline copy; длительные spinner/ambient прекращаются в Reduced Motion. Toast success/info исчезают через 4,5 секунды, hover/focus приостанавливает оставшееся время; error/warning закрываются вручную. Тема переключает конкретные свойства, без transition: all.

### Safe Chat: данные и обработка

`shared/safeChat.ts` содержит типы `SafeCategory`, `SafeAction`, `DictionaryEntry`, `SafeChatSettings`, `SafeAnnotation`, matcher и display engine. Категорий нежелательного текста ровно две; `exception` — allowlist, а не третий уровень наказания. `shared/safeChatSchema.ts` валидирует version 1, предел 500 записей, обычные слова/фразы 2–100 символов, ID, длительность 1–1209600 секунд и replacement. Пользовательский код/regexp не выполняется.

Matcher обрабатывает NFKC, регистр, невидимые/комбинируемые символы, базовые визуальные замены кириллицы/латиницы, транслитерацию, leetspeak, межбуквенные точки/дефисы/подчёркивания/пробелы, повторения букв. Индексы привязаны к UTF-16 оригинала, в том числе после emoji. Учитываются границы слов и фраз; allowlist перекрывает только соответствующий диапазон. Словарь компилируется только при изменении; кеш детекции ограничен 5000 строками, display кеш — WeakMap. Фильтр синхронный и не ждёт сетевую модерацию.

`LocalChatBackend` хранит оригинал в существующем ограниченном буфере main process. Desktop snapshot/events получают display representation. Оригинал выдаётся только main-frame IPC `chat:original` по полному messageKey; для сообщения вне буфера возвращается понятная ошибка. Текст сообщений не добавлен в SQLite или логи. История содержит существующие поля action/duration/success/error и AUTO reason с категорией/ID правила; интерфейс разрешает ID в название правила, без копии сообщения.

`Automoderator` отдельно выбирает наказание и проверяет подключение, capabilities, read-only и защиту owner/moderator. Все действия проходят существующий backend и адаптеры. Есть bounded serial queue, дедупликация, лимит частоты и cooldown; ошибки/пропуски записываются в историю. Доступны none/delete/timeout/ban, presets 10/30 минут, 1/6/24 часа и своё время. При изменении настроек ещё не выполненная работа заново проверяет актуальную политику. Реальная платформа может отказать в действии — в этом случае отображается ошибка, фильтрация не отменяется.

`OverlayServer` использует display engine на границе каждого snapshot и incremental packet; `publicMessage` собирает DTO без локальных аннотаций. Санитизируются также fragments, reply и пользовательские подписи; затронутые emote-фрагменты заменяются обычным текстом, остальные emotes сохраняются. Изменение правил отправляет свежий snapshot активным OBS clients, ключи URL и profile IDs сохраняются. `OverlayRenderer` обновляет строки до paint; desktop preview использует этот же renderer. Локальное раскрытие оригинала не вызывает OBS packet с оригиналом.

### Настройки и совместимость

Отсутствующий safeChat в старых Settings получает version 1 defaults через Zod. Новая SQL migration не требуется: settings JSON и existing moderation_actions подходят без изменения схемы. Старые темы, appearance Auto/Manual, fontFamily, accounts, overlay URLs, desktop preferences остаются на месте. Профили не содержат словарь безопасности: он применяется глобально к отображению с опциональными платформенными выключателями.

Фильтрация/автомодерация ON независимо. При commonRules OFF появляются отдельные Twitch/YouTube флаги; глобальные выключатели остаются главными. Soft маскирует совпавшие фрагменты; blocked скрывает всё сообщение. Kind Mode доступен только при включённом Experimental, меняет отображение, а не detection/punishment. Собственная замена, которая сама совпадает со словарём, заменяется нейтральным `•••`. Random/fuzzy отсутствуют.

## Что изменилось в интерфейсе

### Окно и навигация

Приложение открывается непосредственно в чате. Системная рамка заменена собственной панелью: логотип слева, краткие индикаторы Twitch/YouTube и кнопки свернуть, развернуть/восстановить, закрыть справа. Свободная область панели служит для перетаскивания, двойной клик разворачивает окно. Кнопки исключены из drag region. Закрытие подсвечивается красным при наведении.

Размер, позиция и maximized state сохраняются в `window.json` рядом с данными приложения. При восстановлении геометрия ограничивается доступными рабочими областями дисплеев в DIP; отрицательные координаты второго монитора допустимы. Если монитор исчез, окно возвращается в видимую область. Ошибка записи геометрии не мешает закрытию.

В левой навигации четыре основных пункта: **Чат, Аккаунты, Оформление, Настройки**. **Зрители и модерация** находятся в «Дополнительно». Навигацию можно свернуть; основные кнопки сохраняют подсказки и доступные имена. Внизу — число подключений, простой статус OBS и остановка демо, когда оно запущено. Технические версии/порты не занимают основной экран.

Горячие клавиши: `Ctrl+,` — настройки, `Ctrl+1` — чат, `Ctrl+2` — аккаунты. Они не перехватывают ввод в полях, IME или работу открытого диалога. `Escape` закрывает меню и диалоги. Command Palette не добавлялась: в задании она обозначена второстепенной.

### Чат и подключение

Если ничего не подключено и сообщений нет, внутри области чата показывается приветствие, две кнопки подключения и «Попробовать демо». После успешного OAuth приложение переходит в чат. Для подключённого аккаунта без сообщений показывается ожидание первого сообщения и переход к управлению аккаунтами.

Лента сохраняет виртуализацию и глобальный буфер 2 000 сообщений. Фильтры платформ/событий и выбранный отправитель сохраняются. Если выбранный отправитель временно недоступен, интерфейс использует доступный источник, не стирая предпочтение. Правая карточка зрителя закрыта по умолчанию; она остаётся доступной по клику на имя/аватар или из меню.

Карточки аккаунтов показывают имя, канал и понятное состояние. Ошибки сопровождаются повтором и раскрываемыми подробностями. Выход требует подтверждения; переподключение — нет. Существующая логика восстановления сессий и выбора канала сохранена.

Поля подключения дополнительных URL-каналов показываются при включении экспериментальных функций. Уже добавленные каналы остаются в списке и продолжают работать после выключения этого режима. Для них сохраняется пометка о невозможности модерации; это источники только для чтения.

### Меню сообщений и зрителей

ПКМ по сообщению, имени или аватару открывает собственное меню. С клавиатуры оно вызывается `Shift+F10` или Context Menu. Меню ограничивается видимой областью окна, показывает пользователя и источник, поддерживает стрелки, Home/End, Enter, возврат из подменю, Escape и закрытие кликом снаружи.

Действия: ответить, копировать текст/имя, удалить сообщение, timeout, постоянный бан, разбан, открыть пользователя. Timeout раскрывает 10 секунд, 1/5/10/30/60 минут и ввод собственной длительности. Набор действий определяется capabilities, состоянием подключения и защитой владельца/модераторов; read-only источник не получает write-действий. Для YouTube разбан дополнительно требует доступного ban resource через существующую backend-модель.

Постоянный бан подтверждается в диалоге. Удаление реального сообщения также подтверждается, поскольку у платформенного API нет undo. Демо-модерация остаётся локальной. Таблица зрителей использует то же меню при наличии сообщения соответствующего источника; без него доступны просмотр сохранённого профиля и копирование имени. Права не синтезируются из старой записи зрителя.

### Оформление и OBS

Редактор сохраняет семь тем, профили и общий renderer preview/OBS. В основной части — стиль, текущий шрифт с кнопкой изменения, переключатели видимости, размер текста в px и три плотности. Точные параметры остаются в закрытом по умолчанию Advanced и доступны независимо от Experimental.

Auto по-прежнему рассчитывает аватар, межстрочный интервал и расстояния одновременно по размеру текста и плотности. Manual фиксирует конкретный параметр. Автоматический display limit относится только к отображению overlay; глобальный буфер чата не меняется. Reset точных настроек не сбрасывает тему, размер текста, плотность и переключатели видимости. Предыдущая миграция сохраняет явные старые числовые параметры как Manual.

Live Preview отражает изменения сразу. При пустом буфере показываются прежние два примера flamberor с локальным аватаром; примеры не отправляются в backend и OBS. Для OBS пользователь нажимает «Добавить чат в OBS», копирует URL и вставляет его в Browser Source. Изменения профиля применяются к открытому OBS после сохранения. Порт, сброс ключа и диагностика доступны через экспериментальные инструменты.

### Системные шрифты

Диалог показывает выбранный шрифт, поиск и виртуальный список: название и пример непосредственно этим шрифтом. В RU используется «Южно-эфиопский грач увёл мышь за хобот на съезд ящериц», в EN — «The quick brown fox jumps over the lazy dog». Работают стрелки, выбор, Apply/Cancel и возврат к Segoe UI. До Apply изменения не сохраняются.

В Настройках выбирается шрифт основного чата; в Оформлении — шрифт конкретного OBS-профиля. Названия валидируются, CSS family экранируется и получает запасной набор Segoe UI/Arial/sans-serif. Отсутствующий сохранённый шрифт не удаляется из профиля: текст отображается запасным. При невозможности прочитать системный список доступны три стандартных варианта с пояснением.

Список получает main process фиксированным read-only вызовом Windows `InstalledFontCollection` через скрытый PowerShell без аргументов от renderer. Есть timeout, предел вывода, фильтрация и кэш на время процесса. Пользовательский JavaScript/команды через IPC не принимаются. [Документация Microsoft](https://learn.microsoft.com/en-us/dotnet/api/system.drawing.text.installedfontcollection?view=windowsdesktop-10.0).

### Настройки, уведомления и движение

Настройки содержат тему приложения, акцент, масштаб, стиль/шрифт основного чата, RU/EN, звуки, громкость, тест звука и Reduced Motion. Экспериментальные функции выключены по умолчанию. Их включение показывает URL-каналы, диагностику, Developer Mode и серверные параметры; отдельные флаги типизированы и допускают независимое отключение в модели.

Уведомления имеют success/info/warning/error состояния, закрытие и выходную анимацию. Ошибки показывают короткое сообщение и подробности по раскрытию. Успешные уведомления исчезают автоматически; ошибка/предупреждение остаётся до закрытия. Звуки — короткие синтезированные сигналы подключения, отключения, ошибки, уведомления и модерации. Они включены по умолчанию с громкостью 25%; повторные сигналы ограничены. Обычные сообщения и hover не озвучиваются.

Переходы короткие: 140–160 ms. Reduced Motion по умолчанию следует Windows и имеет ручное переопределение. Модальные окна и контекстные меню выводятся через portal, чтобы стили и прокрутка родительских карточек не сдвигали их. Диалоги имеют focus trap и возвращают фокус. Сохранены dark UI, зелёный акцент, светлая тема и существующий визуальный язык.
